# Vergabeplanung

# Vergabeplanung ist ein Visual für Microsoft PowerBI, um die Vergabeplanung im PSM Controlling darstellen zu können.  
Der ursprüngliche Code wurde von Microsoft entwickelt und unter der MIT-Lizenz veröffentlicht.  
Ich habe den Code erweitert und angepasst, um zusätzliche Funktionen für unsere internen Anforderungen bereitzustellen.
